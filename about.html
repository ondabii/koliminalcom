About koliminal

불필요함을 걷어낸
미니멀 기술 큐레이션

koliminal.com은 복잡한 서버 레이어와 불필요한 번들 오버헤드를 배제하고, 최상의 로딩 속도와 읽기 경험을 제공하기 위해 만들어진 정적 프론트엔드 미디어입니다.

0.1초 미만의 초속 로딩

Next.js Static Export와 System Font를 채택하여 외부 다운로드 지연 시간을 제로에 가깝게 유지합니다.

정직한 시맨틱 구조

검색 엔진 크롤러와 실제 방문자 모두에게 동일하게 보이는 100% 노출형 HTML5 시맨틱 본문만을 작성합니다.

Ponytail & YAGNI 철학

필요하지 않은 외부 의존성을 배제하고, 가장 심플하면서도 견고한 기술만을 엄선하여 전달합니다.

기술 스택 (Technical Architecture)

  • Framework: Next.js 15 (App Router, Static Export)
  • UI Library: React 19 & TypeScript
  • Styling: Tailwind CSS (Sleek Dark Theme)
  • Hosting: GitHub Pages & Static Edge CDN
